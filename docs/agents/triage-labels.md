# Triage Labels

This folder does not currently apply labels through an external issue tracker.

Canonical roles to preserve if a tracker is added later:

- `needs-triage`: maintainer needs to evaluate.
- `needs-info`: waiting on reporter.
- `ready-for-agent`: fully specified and agent-ready.
- `ready-for-human`: needs human implementation or judgment.
- `wontfix`: will not be actioned.
